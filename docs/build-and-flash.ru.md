# Сборка и прошивка

Вы собираете прошивку в Visual Studio с плагином VisualGDB и прошиваете ESP32 по кабелю USB. На
этой странице описаны шаги для прошивки {{ app_version }}.

---

## Требования

| Компонент | Версия |
|-----|--------|
| Visual Studio | 2022 Community с VisualGDB 5.6 |
| Ядро Arduino | `esp32` **2.0.11** |
| Плата | ESP32 Dev Module, основная плата Ver 1.1 |

!!! warning "Используйте только ядро 2.0.11"
    В ядре 3.x нет имён событий WiFi, которые использует прошивка, а его библиотеки не совпадают с
    теми, что лежат в папке `Libs`. Сборка завершается ошибкой. Другие версии 2.0.x не проверялись.

---

## Установите ядро

1. В Visual Studio откройте **«Tools → VisualGDB → Manage VisualGDB Packages»**.
2. Отметьте **«Show old packages»**. Иначе Visual Studio скрывает версию 2.0.11.
3. Выберите пакет **esp32** версии 2.0.11 и установите его.

---

## Получите исходники

1. Клонируйте репозиторий вместе с подмодулями `Libs/NTPClient` и `Libs/WebSerial`. В Visual Studio
   нет команды для подмодулей; в терминале выполните `git clone --recurse-submodules` с адресом
   репозитория или `git submodule update --init` в уже клонированной копии.
2. Откройте `Software/Software_ver_2/HAQuDA_Esp32/HAQuDA_Esp32.sln` в Visual Studio.

---

## Задайте переменные сборки

Прошивка берёт четыре текста из переменных сборки. В исходниках их намеренно нет.

| Переменная | Назначение |
|------------|----------|
| `AP_ssid_uv` | Имя точки доступа лампы. Также имя хоста лампы в вашей сети. |
| `AP_pass_uv` | Пароль точки доступа, от 8 до 63 символов. |
| `DDNS_Domain_uv` | Домен DuckDNS. <span class="wip">WIP</span> |
| `DDNS_Token_uv` | Токен DuckDNS. <span class="wip">WIP</span> |

1. Откройте свойства проекта VisualGDB для `HAQuDA_Esp32` (**«Project → VisualGDB Project
   Properties»**).
2. Задайте четыре пользовательские переменные.

VisualGDB сохраняет ваши значения в файле `HAQuDA_Esp32.vgdbproj.<user>.user`, который Git
игнорирует. Никогда не фиксируйте в репозитории реальные значения.

!!! note "WIP"
    Обновления DuckDNS не готовы: лампа их не отправляет. Для сборки оба значения всё равно нужны.

---

## Соберите прошивку

1. На панели инструментов выберите конфигурацию **«Debug»** и платформу **«ESP32_Dev_Module»**.
2. Выберите **«Build → Build Solution»**.
3. Результат лежит в `Software/Software_ver_2/HAQuDA_Esp32/Output/ESP32_Dev_Module/Debug`.

---

## Прошейте лампу

Подключите лампу к компьютеру кабелем USB. На основной плате стоит преобразователь USB–UART
FT232RL.

| Способ | Шаги |
|--------|------|
| UART | Выберите **«Debug → Program and Start Without Debugging»**. По умолчанию VisualGDB использует порт `COM8`; если у вас другой, выберите свой порт в свойствах проекта. Микросхема сама переводит ESP32 в режим загрузчика. |
| JTAG с OpenOCD | Подключите J-Link к разъёму JTAG и выберите **«Debug → Start Debugging with GDB»**. |

### Проверьте версию

Откройте терминал последовательного порта лампы на скорости 115200 бод, 8N1, и перезапустите
лампу. Сначала загрузчик ESP32 печатает свои строки. Строка `HAQuDA firmware v{{ app_version }}`
идёт после них.

---

## Сборки из GitHub Actions

Не прошивайте сборки, которые создаёт GitHub Actions. Рабочий процесс ставит самое новое ядро
Arduino вместо 2.0.11, и оно не подходит этой прошивке. Соберите прошивку сами, как описано выше.
