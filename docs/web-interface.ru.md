# Веб-интерфейс

Лампа запускает небольшой веб-сервер, как только подключилась к вашей сети WiFi или создала
собственную точку доступа. Страницы только на английском.

!!! note "У страниц нет пароля"
    Любой, кто может открыть лампу в браузере, может добавить или удалить её сеть WiFi. Пароль
    вашей сети лампа получает по обычному HTTP. Пользуйтесь страницами в сети, которой доверяете.

---

## Адреса страниц

| Режим лампы | Адрес |
|-------------|-------|
| Точка доступа | `http://192.168.4.22/` после подключения к собственной сети WiFi лампы. Введите адрес вручную: автоматическое открытие страницы — <span class="wip">WIP</span>. |
| Подключена к вашей сети | `http://` и адрес, который роутер выдал лампе. Лампа не сообщает свой адрес <span class="wip">WIP</span>; найдите его в списке клиентов роутера под именем точки доступа лампы. |

| Адрес | Содержимое |
|-------|----------------|
| `/` | Главная страница. |
| `/wifi_manager` | Форма добавления сети WiFi. |
| `/webserial` | Журнал лампы в реальном времени. В режиме точки доступа недоступен: адрес открывает главную страницу. |

На любой другой адрес в вашей сети лампа отвечает пустой страницей 404. В режиме точки доступа
любой адрес, кроме маршрутов форм, возвращает главную страницу.

---

## Главная страница

В заголовке написано **«HAQuDA WEB SERVER»**, под ним — **«Hello, world!»**.

| Элемент | Действие |
|---------|------------|
| Ссылка **«Add WiFi credentials»** | Открывает форму [Страница Add WiFi credentials](#страница-add-wifi-credentials). |
| Кнопка **«Delete»** под **«Delete stored WiFi credentials»** | Удаляет все сохранённые сети. Лампа остаётся подключённой до следующего запуска; после запуска она создаёт точку доступа. |
| Кнопка **«Show»** под **«Show stored WiFi credentials»** | Не нажимайте её. <span class="wip">WIP</span> |

На **«Delete»** страница отвечает **«Deleted all WiFi credentials»**. Если сохранённых сетей нет,
ответ — **«Error while deleting WiFi credentials»**.

!!! note "WIP"
    **«Show»** не готова и может привести к сбою лампы. Не нажимайте её.

## Страница Add WiFi credentials

В заголовке написано **«ESP Wi-Fi Manager»**.

| Поле | Ввод |
|------|-------------|
| **«SSID»** | Имя вашей сети WiFi, не длиннее 31 символа. |
| **«Password»** | Пароль вашей сети, не длиннее 31 символа. |
| **«IP Address»** | Заполнено значением `192.168.1.200`. Лампа это поле игнорирует. <span class="wip">WIP</span> |
| **«Gateway Address»** | Заполнено значением `192.168.1.1`. Лампа это поле игнорирует. <span class="wip">WIP</span> |
| **«Submit»** | Сохраняет сеть. Примерно через 3 секунды лампа перезапускается и пробует подключиться к сети. |

!!! note "WIP"
    Хранение нескольких сетей не готово: если сеть уже сохранена, лампа отвечает **«Error reading
    stored WiFi credentials»**. Сначала нажмите **«Delete»** на главной странице.

### Ответы формы

| Ответ | Причина | Действие |
|-------|---------|------------|
| **«Error check WiFi creds»** и **«Go back»** | Поле SSID или Password пусто. | Нажмите **«Go back»**: откроется главная страница. Снова нажмите **«Add WiFi credentials»** и заполните оба поля. |
| **«Error writing new WiFi creds in file system»** и **«Error reading stored WiFi credentials»** | Сеть уже сохранена. | Нажмите **«Delete»** на главной странице и добавьте вашу сеть снова. |
| **«Error writing new WiFi creds in file system»** и **«Error saving stored WiFi credentials»** | Лампа не смогла записать файл. | Попробуйте ещё раз. Если ошибка повторяется, отключите лампу от питания и включите снова. |
| **«Success»** и **«Saved new WiFi credentials»**, затем **«Device will restart in 3 seconds»** | Сеть сохранена. | Дождитесь перезапуска. Лампа подключится к сети; см. [Быстрый старт](quick-guide.md#подключите-лампу-к-вашему-wifi). |

## Страница журнала

Откройте `/webserial`, чтобы читать журнал лампы в реальном времени. Примерно через секунду после
открытия страницы лампа присылает строки, сохранённые с последнего запуска; следующие приходят по
мере появления. При каждом запуске лампа очищает сохранённый журнал.

!!! note "Режим точки доступа"
    Страница журнала недоступна в режиме точки доступа: адрес открывает главную страницу. Читайте
    журнал, когда лампа работает в вашей сети.

Каждая строка имеет вид `time - level : message`.

| Часть | Содержимое |
|-------|------------|
| `time` | `Fail get time!` Время по часам в строках журнала не готово. <span class="wip">WIP</span> |
| `level` | `Info` или `ERROR`. |
| `message` | Событие. Сообщения перечислены в разделе [Сообщения журнала](troubleshooting.md#сообщения-журнала). |
