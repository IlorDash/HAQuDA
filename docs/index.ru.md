# HAQuDA

HAQuDA (Home Air Quality Display And so on) — настольная лампа, которая показывает состояние дома
цветом своего света: качество воздуха, температуру и влажность.

Лампа передаёт человеку состояние дома с первого взгляда: вы читаете цвет, а не анализируете
числа. У каждой величины три границы: синий ниже нижней границы, красный выше верхней границы, а
между ними плавный переход через зелёный. eCO2 и TVOC меняются ступенями, а не плавно; см.
[Шкала цветов](display-modes.md#шкала-цветов).

## Технические характеристики

| Параметр | Значение |
|----------|----------|
| Версия прошивки | {{ app_version }} |
| Контроллер | модуль ESP32-WROOM-32 |
| Датчики | DHT11 (температура, влажность), CCS811 (eCO2, TVOC), ZH03B (твёрдые частицы) |
| Светодиодная матрица | 12 × 9 = 108 адресуемых светодиодов WS2812B на девяти линейках по двенадцать, на трубке, закреплённой на плате |
| Рассеиватель | Матовый полупрозрачный белый колпак над трубкой; непрозрачное основание с электроникой |
| Габариты | Цилиндр диаметром 90 мм и высотой 130 мм |
| Питание | 5 В через разъём Micro-USB, блок питания 5 В 2 А |
| Выходы | Два разъёма USB-A для зарядки других устройств |
| Связь | WiFi в режиме клиента к сохранённой сети; собственная точка доступа `192.168.4.22` как запасной вариант |
| Службы | Веб-сервер на порту 80, журнал WebSerial, время по NTP с фиксированным смещением UTC+3 (только в режиме клиента) |
| Динамический DNS (DuckDNS) | <span class="wip">WIP</span> |
| Обновление картинки | Датчики опрашиваются каждые несколько секунд; матрица перерисовывается раз в минуту по среднему значению за эту минуту |
| Индикация ошибок | Световые эффекты и строки журнала |

## Измеряемые параметры

| Параметр | Датчик | Единица | Типичная точность | Показывается на матрице |
|----------|--------|---------|-------------------|-------------------------|
| Температура | DHT11 | °C | ±2 °C | Multi (нижняя зона), standard, night |
| Влажность | DHT11 | % | ±5 %RH | Standard, night |
| eCO2 | CCS811 | ppm | — | Multi (средняя зона), standard, night |
| TVOC | CCS811 | ppb | — | Standard, night |
| PM2.5 | ZH03B | мкг/м³ | — | Multi (верхняя зона), standard, night |
| PM1.0, PM10 | ZH03B | мкг/м³ | — | Нет |

Значения точности — данные производителя, на лампе они не измерялись.

Границы каждой величины и получающиеся цвета описаны в разделе [Режимы отображения](display-modes.md#шкала-цветов).

## Режимы отображения

| Режим | Матрица показывает |
|-------|--------------------|
| Multi (по умолчанию) | Три горизонтальные зоны: температура, eCO2 и PM2.5. |
| Standard | Вся матрица цветом одной выбранной величины. |
| Night | Цвет одной выбранной величины в трёх столбцах и белый индикатор прогресса ночи в остальных. |

Лампа запускается в режиме multi. Выбор режима отображения без изменения прошивки не готов
<span class="wip">WIP</span>; см. [Выбор режима](quick-guide.md#выберите-режим-отображения).

Подробности — в разделе [Режимы отображения](display-modes.md).
